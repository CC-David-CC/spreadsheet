# Spreadsheet optional lifecycle research

Based on 1f2d00924; no deployment. The optional per-window lifecycle reports dirty edits and outstanding file selection, loading, saving, conversion and export work; quiescence makes the app inert and reversible without explicitly committing an active cell. Real in-cell input already marks the workbook dirty before Jspreadsheet commits. Formula recalculation remains the existing behavior. The host retains legacy handling for apps without this contract and disposal is idempotent.

Run `node --test tests/spreadsheet-lifecycle-reference.test.mjs`. Build an isolated spreadsheet catalog, run `tests/jsketcher-preview-csp.py --isolated` against it, and run `tests/spreadsheet-lifecycle-session-review.test.mjs` with CODI_TEST_URL and CODI_TEST_CDP set to the loopback preview and dedicated Chromium. The signed-account desktop test checks an uncommitted cell across a cancelled sign-out and server save; a real programmatic worksheet edit invalidates confirmation; a held save preserves a formula on the server; a stale version is refused without overwriting the external copy; failed sign-out releases the app; account switching denies the next account access and disposes idempotently. Mobile, multiple spreadsheet windows and worker interruption during conversions were not qualified by this test.
